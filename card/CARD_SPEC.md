# 鸿蒙服务卡片规范

## 概述

校园搭子提供 5 张原子化服务卡片，覆盖桌面和通知栏两类场景。

## 卡片清单

| 卡片 ID | 名称 | 类型 | 尺寸 | 更新 | 触发条件 |
|---------|------|------|------|------|---------|
| `MorningBriefCard` | 智能早报 | Form 2×2 | 2×2 | 30min / 手动 | 桌面可见 |
| `ScheduleCard` | 今日课表 | Form 4×2 | 2×2, 4×2 | 1h / 手动 | 桌面可见 |
| `ExamCountdownCard` | 考试倒计时 | Form 1×2 | 1×2, 2×2 | 1h | 考试周 |
| `BalanceCard` | 一卡通余额 | Form 1×2 | 1×2 | 30min | 余额<20元 |
| `PackageCard` | 快递提醒 | Notification | - | 事件驱动 | 快递到站 |

## 数据源

所有卡片通过 HTTP 调用校园搭子 API 获取数据：

```
GET /api/card/{cardId}    →  返回 JSON 卡片数据
```

认证方式：`Authorization: Bearer {token}`（小艺 Skill Token）

## 实现方式

每张卡片对应一个 ArkTS FormExtensionAbility，通过 `onUpdateForm` 生命周期回调定时请求 API 更新卡片内容。

详见各卡片模板：`card/templates/`
