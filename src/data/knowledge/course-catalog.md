# 培养方案与选课指南

## 课程结构

### 总学分要求
本科四年制专业总学分一般为 160-180 学分，其中：
- 通识教育课程：40-50 学分（含思政、外语、体育、计算机等）
- 学科基础课程：30-40 学分
- 专业必修课程：40-50 学分
- 专业选修课程：20-30 学分
- 实践教学环节：20-30 学分（含毕业设计/论文、实习等）

### 绩点（GPA）计算
采用 4.0 制计算方法：
- 90-100 分 → 4.0
- 85-89 分 → 3.7
- 82-84 分 → 3.3
- 78-81 分 → 3.0
- 75-77 分 → 2.7
- 72-74 分 → 2.3
- 68-71 分 → 2.0
- 64-67 分 → 1.5
- 60-63 分 → 1.0
- 60 分以下 → 0

### 学位授予条件
- 修完培养方案规定的全部课程并取得规定学分
- 平均绩点（GPA）不低于 2.0
- 外语达到学校规定的水平（CET-4 425 分以上）
- 无记过及以上纪律处分

## 选课规则

### 选课阶段
每学期末进行下学期选课，分为三个阶段：
1. 预选阶段：学生根据培养方案预选课程，选课人数超过课容量时随机抽签
2. 正选阶段：预选未中签的学生重新选课，先到先得
3. 补退选阶段：开学第一周，可补选或退选课程

### 学分上限
每学期选课学分上限为 30 学分（不含重修课程），下限为 15 学分（毕业班除外）。

### 重修
课程不及格可申请重修，重修次数不限。重修成绩按实际分数记载，但绩点计算时标记为重修。

## 转专业政策

### 申请条件
- 大一、大二在校本科生
- 第一学年课程全部及格
- 平均绩点达到转入专业要求（一般不低于 3.0）
- 未受过纪律处分

### 申请时间
每年 4 月（大二下学期）和 9 月（大二上学期开学初）各有一次转专业申请窗口。

### 申请流程
1. 填写转专业申请表
2. 提交成绩单及相关材料至所在学院教务办
3. 所在学院审核并签署意见
4. 转入学院组织面试或笔试
5. 教务处公示拟转专业名单
6. 公示无异议后办理学籍变更

### 注意事项
- 艺术类、体育类专业不得转入普通类专业
- 每个学生在校期间只能转一次专业
- 转专业后需补修转入专业已开设的必修课程

## 辅修与双学位

### 辅修
学有余力的学生可申请辅修其他专业，完成辅修培养方案（一般为 25-30 学分），获得辅修证书。

### 双学位
辅修专业与主修专业属于不同学科门类，且完成双学位培养方案（一般为 50-60 学分，含毕业论文）者，可申请双学位。
