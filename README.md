# 校园搭子 (Campus Buddy)

鸿蒙高校创新赛 Agent 赛道项目 — 大学生的校园生活 Agent。

**一句话：说一句话，它帮你把校园琐事全安排好。**

## 快速开始

```bash
# 安装依赖
npm install

# 交互式对话（命令行）
npm run dev

# 启动 HTTP API
npm run api      # → http://localhost:3456
```

## 项目结构

```
src/
├── agent.ts          # Agent 主入口（意图识别 → 场景路由 → 返回回复）
├── index.ts          # 命令行交互入口
├── test-run.ts       # 自动化测试脚本
├── models/           # 类型定义 & 数据模型
├── core/             # 核心引擎
│   ├── intent/       #   意图识别（关键词 + 正则）
│   ├── orchestrator/ #   任务编排（并行/串行、超时降级）
│   ├── memory/       #   三层记忆（短期/中期/长期）
│   └── triggers/     #   主动触发器
├── scenes/           # 场景实现
│   ├── shower.ts     #   洗澡助手
│   ├── schedule.ts   #   课表管家
│   ├── card.ts       #   一卡通管家
│   └── delivery.ts   #   快递 & 外卖 + 路线规划 🆕
├── data/             # 模拟数据
├── services/         # 服务适配层
└── api/              # HTTP API
```

## 核心场景

| 场景 | 用户说 | Agent 做什么 |
|------|-------|-------------|
| 洗澡助手 | "我要洗澡" | 查余额 + 拥挤度 → 建议 |
| 课表管家 | "明天什么课" | 查课表 + 天气 → 早八预警 |
| 一卡通管家 | "卡里还有多少钱" | 余额 + 消费分析 + 分类汇总 |
| 快递追踪 🆕 | "查快递" | 到站状态 + 取件码 + 取件点 |
| 外卖追踪 🆕 | "外卖到了吗" | 配送状态 + 预计送达 + 骑手信息 |
| 路线规划 🆕 | "帮我规划路线" | 多取件点排序 + 步行时间 + 时间预估 |
| 天气 | "今天天气" | 天气 + 穿衣建议 |
| 饮水 | "今天喝了多少水" | 饮水进度 |

## 多轮对话

Agent 支持上下文保持和指代消解：

```
用户："我要洗澡"    →  余额 3.2 元，澡堂空闲
用户："够不够？"    →  够的，大概能洗 1 次 （知道在问洗澡）
用户："几点去？"    →  你习惯 17:30 洗，现在人少随时去
```

## API

```
POST /api/chat     →  { "text": "我要洗澡" }
GET  /api/health   →  { "status": "ok" }
POST /api/trigger  →  手动触发定时任务
```

## 技术栈

- TypeScript + Node.js
- 意图识别：关键词 + 正则规则匹配（可升级 LLM）
- 任务编排：并行/串行自动判断 + 3s 超时降级
- 记忆模型：短期（会话上下文）/ 中期（行为习惯）/ 长期（校园常识）
