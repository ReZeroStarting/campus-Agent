## 🎯 一句话说清楚

大学生的校园 Agent。说"明天什么课"，它自动告诉你课表 + 天气要不要带伞 + 一卡通还够不够吃饭。**从单点查询到场景闭环，从被动响应到主动服务。**

## ✨ 核心场景一览

| 你只要说 | Agent 自动做 |
|----------|------------|
| ☀️ **早安** | 天气 + 课表 + 考试倒计时 + 快递取件码 + 今日活动 + 余额提醒 |
| 📚 **明天什么课** | 查课表 → 联动天气提醒带伞 → 联动一卡通余额预警 |
| 🚿 **我要洗澡** | 查余额 → 判断够不够 → 看澡堂拥挤度 → 推荐时间 → 洗完扣费 |
| 💳 **卡里还有多少钱** | 余额 + 今日/本周消费 + 分类汇总（早餐/午餐/洗澡） |
| 📦 **查快递** | 到站状态 + 取件码 + 「帮我规划路线」多取件点智能排序 |
| 📝 **高数什么时候考** | 简称映射 → 倒计时 + 时间地点 + 考试备注（闭卷/带计算器） |
| 🏫 **教三有空教室吗** | 占用反查 + 插座/空调/大小多维度筛选 |
| 📊 **绩点够不够3.5** | GPA 总览 + 学期趋势 → 精确计算所需分数 + 可行性判定 |
| 💬 **有什么讲座** | 论坛自动提取：活动时间/地点/组织方/是否有抽奖 |
| 🗺️ **去哪打成绩单** | 服务反查 → 行政楼 2 楼 204，含楼层指引和开放时间 |

**10 个场景 · 11 个意图类别 · 28 个源文件 · 5700+ 行 TypeScript**

## 🧠 技术创新点

### 1. 一句话触发服务链
不是"先查课表、再查天气、再查余额"——说**一句话**，Agent 自动并行编排，3s 内返回全量结果。单个服务超时不影响整体。

### 2. 自然多轮对话 + 指代消解
```
用户：我要洗澡    →  余额 3.2，澡堂空闲
用户：够不够？    →  够的，够洗 1 次    （知道在问洗澡余额）
用户：几点去？    →  你习惯 17:30 去，现在人少随时去
```

### 3. 论坛信息自动提取
不是简单的帖子列表。16 个论坛帖子 → 自动解析出 **11 条结构化信息点**：
- 📅 活动：时间/地点/组织方/是否有抽奖
- 📦 二手：商品/成色/价格/联系方式
- 🔍 失物：物品特征/丢失地点/时间
- 📊 课评：难度/作业量/给分三维展示

### 4. 服务反查（Reverse Lookup）
不说"行政楼在哪"，说**"去哪打成绩单"** → 反向匹配 18 栋建筑的服务 → 定位到具体楼层和窗口。

### 5. 模块化场景架构
新增场景不影响已有场景。每个场景独立文件，暴露统一接口 `(text) => { text, suggestions }`。意图识别 → 场景路由 → 数据聚合，三层解耦。

## 🏗️ 系统架构

```
用户输入 → 意图识别(11类) → 任务编排(并行/串行) → 场景路由(10场景)
                ↕                    ↕
          记忆引擎(3层)         主动触发器(3种)
                ↕
          数据适配层(Mock → 真实API)
```

详见 [`ARCHITECTURE.md`](./ARCHITECTURE.md)

## 📁 项目结构

```
src/
├── agent.ts              # 主入口：意图识别 → 场景路由 → 返回回复
├── core/                 # 核心引擎
│   ├── intent/           #   意图识别（关键词+正则，11类）
│   ├── orchestrator/     #   任务编排（并行/串行，3s超时降级）
│   ├── memory/           #   三层记忆（短期/中期/长期）
│   └── triggers/         #   主动触发器（低余额/早八/拥挤）
├── scenes/               # 场景实现（11个文件）
│   ├── shower.ts         #   洗澡助手（扣费闭环）
│   ├── schedule.ts       #   课表管家（天气+余额联动）
│   ├── card.ts           #   一卡通（消费分析）
│   ├── delivery.ts       #   快递外卖（追踪+路线）
│   ├── forum.ts          #   校园论坛（信息提取）
│   ├── map.ts            #   校园地图（服务反查）
│   ├── morning-brief.ts  #   智能早报（聚合推送）
│   ├── exam.ts           #   考试倒计时
│   ├── classroom.ts      #   空闲教室
│   └── grade.ts          #   绩点计算器
├── data/mock.ts          # 模拟数据（课表/一卡通/论坛/地图/考试/成绩）
├── services/             # 服务适配（天气/课表数据获取）
└── api/                  # HTTP API
```

## 🛠️ 技术栈
